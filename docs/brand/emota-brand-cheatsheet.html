Quick start

Three lines to brand a page

Save the stylesheet next to your page, link it, and put em-body on the body. The file imports Montserrat itself. Dark is the brand default; set data-em-theme="light" on <html> or any container for the light variant.

<link rel="stylesheet" href="emota-brand.css">

<body class="em-body">
  <p class="em-eyebrow">Event console</p>
  <h1 class="em-h1">Welcome back</h1>
  <button class="em-btn em-btn--primary">Sign in</button>
</body>

<!-- Light variant, whole page or one region -->
<html data-em-theme="light">
<section data-em-theme="light">...</section>

Logo

Lockup files and rules

The lockup reads "Emota, Inizio Engage". The source files live in the VerbCloud repository at src/client/assets/, 4167 by 2151 pixels with a transparent background.

emota-logo-white.png on dark grounds

emota-logo-blackberry.png on light grounds

  • Pick the file by background brightness. VerbCloud uses the blackberry file when the ground's perceived brightness is above 150 out of 255, and the white file otherwise.
  • Show the full lockup sparingly. In VerbCloud it appears only on sign-in screens and the default holding screen. Signed-in screens use the two-line product signature instead.
  • Size it at 178px wide in interface chrome (.em-lockup) and keep the height automatic.
  • Alt text: "Emota, an Inizio Engage company".
  • Never recolour or retype it. Use the two supplied files as they are.
